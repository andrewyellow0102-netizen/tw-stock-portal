# TW Stock Portal 台股分析站台

**網址：** http://localhost:8000

---

## 一、功能地圖

### 1. 首頁（`/`）
輸入股票代碼（4 碼，如 `2330`、`3081`），按下搜尋即可到達個股頁面。

### 2. 個股頁（`/stock/{代碼}`）
包含四個區塊：

#### 📋 報價卡片
即時顯示：開盤價、最高、最低、昨收、成交量、本益比（PE）、股價淨值比（PB）

#### 📈 走勢圖（主圖）
- **收盤價線**：黃色線，記錄每天收盤價
- **均線（MA）**：可點擊切換顯示
  - MA5（藍線）：5 日均線，短線參考
  - MA20（紅線）：20 日均線，中線參考
  - MA60（紫線）：60 日均線，長線參考
- 右上角可切換時間區間：5天 / 1個月 / 3個月 / 6個月 / 1年

#### 📊 技術指標子圖
點擊「KD」或「RSI」按鈕可展開對應子圖

#### 🏢 基本面資料
- **追蹤 EPS**：近 8 季每股盈餘（紅色=正，綠色=負）
- **月營收**：當月營收、年月增減（YoY）、月增減（MoM）
- **關鍵財務比率**：每股淨值、ROE（股東權益報酬率）、負債比

### 3. 自選股（`/watchlist`）
雙頁籤設計：
- **自選股**：已收藏的股票列表，點擊代碼進入個股頁，🔔設定價格警示
- **價格警示**：已設定的警示條件，符合條件時顯示⚠️

## 二、專業名詞說明

### 技術分析名詞

#### 均線 MA（Moving Average）
一段時間的平均收盤價。均線向上代表價格動能偏多，向下偏空。
- MA5：5 日均線，最敏感，適合短線
- MA20：20 日均線，法人常用中線
- MA60：60 日均線，判斷長線趨勢

#### KD 指標（隨機指標）
由 K 線和 D 線組成，範圍 0~100。
- K > 80：進入超買區，可能會跌
- K < 20：進入超賣區，可能會漲
- K 線由下穿越 D 線（金叉）→ 買進訊號
- K 線由上穿越 D 線（死叉）→ 賣出訊號

#### RSI（相對強弱指標）
衡量價格上漲與下跌的強度，範圍 0~100。
- RSI > 70：超買區，慎防回調
- RSI < 30：超賣區，低點可能反彈
- RSI6：短周期（6天），敏感
- RSI12：長周期（12天），穩定

#### 本益比 PE（Price-to-Earnings Ratio）
股價 ÷ 每股盈餘（EPS）。代表「以現在價格買入，多久回本」。
- PE 越低 = 越便宜（理論上）
- 不同產業 PE 水準差異很大，半導體平均 25~35 倍

#### 股價淨值比 PB（Price-to-Book Ratio）
股價 ÷ 每股淨值。衡量股價相對於公司帳面價值的溢價。
- PB < 1：股價低於淨值，可能被低估
- PB > 3：市場給予較高成長預期

---

### 基本面名詞

#### EPS（每股盈餘，Earnings Per Share）
公司稅後淨利 ÷ 流通在外股數。代表「每一股賺多少錢」。
- EPS 越高 = 越會賺錢
- 看 EPS 重點在**趨勢**（是否持續成長）而非單一數字

#### ROE（股東權益報酬率，Return on Equity）
稅後淨利 ÷ 股東權益。代表「公司用自有資金賺錢的效率」。
- ROE > 15%：體質良好
- ROE > 25%：極優秀（台積電約 25~36%）

#### 負債比（Debt Ratio）
總負債 ÷ 總資產。衡量公司資金來源有多少來自借貸。
- 負債比 < 50%：財務體質穩健
- 負債比 > 70%：利息負擔重，景氣不好時風險高

#### 月營收（Monthly Revenue）
公司每個月的營業收入總和，是最即時的景气訊號。
- **YoY（年增率）**：與去年同月比，成長對股價正面
- **MoM（月增率）**：與上月比，觀察趨勢是否持續

#### 累計營收
年初至本月的總營收，用來判斷全年營收是否達標。

## 三、資料來源說明

| 資料 | 來源 |
|------|------|
| 即時報價 | Yahoo Finance（yfinance） |
| K線/技術指標 | Yahoo Finance（歷史資料計算） |
| 季度EPS | Yahoo Finance（財務報表） |
| 月營收 | 證交所 OpenAPI（當月最新，僅一筆） |
| 基本面比率 | Yahoo Finance（PE、PB、ROE） |

**限制：**
- 月營收目前僅顯示當月最新一筆，無歷史資料
- 歷史月營收需透過 FinMind 或手動累積

## 四、已知限制

1. **無 K 線（陰陽燭）**：目前顯示的是收盤價線圖，不是傳統 K 線圖
2. **月營收只有一筆**：TWSE OpenAPI 設計如此
3. **無法人籌碼資料**（三大法人買賣超）
4. **無期貨/選擇權**相關資料
5. **無產業分析/同業比較**
